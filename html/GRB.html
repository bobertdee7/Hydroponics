The multilayer greenhouse window was designed to protect plants from the Moon’s harsh environment. It has three layers, and each one has a different job. The first layer is fused silica glass, which can survive extremely high temperatures. The second layer is aluminum oxynitride, a very strong transparent material that can protect the greenhouse from small asteroid impacts. The third layer is made of hydrogen‑rich hBNNTs, which block dangerous galactic cosmic radiation.

Other options were considered, like using metal‑organic frameworks (MOFs) or making a single‑layer window. MOFs can store more hydrogen but only work at extremely cold temperatures and are not naturally transparent. A single‑layer window was also not practical because no single material can handle radiation, heat, and impacts all at once. The multilayer design is better because it lets each layer focus on one job, can be partly built using lunar materials, and can be upgraded in the future by replacing individual layers.

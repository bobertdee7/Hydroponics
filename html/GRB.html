The multilayer greenhouse window was designed to protect plants from the Moon’s harsh environment. It has three layers, and each one has a different job. The first layer is fused silica glass, which can survive extremely high temperatures [1]. The second layer is aluminum oxynitride, a very strong transparent material that can protect the greenhouse from small asteroid impacts [2]. The third layer is made of hydrogen rich hBNNTs, which will block dangerous galactic cosmic radiation [3].

Other options were considered, like using metal organic frameworks (MOFs) or making a single layer window. MOFs can store more hydrogen but only work at extremely cold temperatures and are not naturally transparent [4;5]. A single layer window was also not practical because no single material can handle radiation, heat, and impacts all at once. The multilayer design is better because it lets each layer focus on one job, can be partly built using lunar materials [6], and can be upgraded in the future by replacing individual layers.
